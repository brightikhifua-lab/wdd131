Bright Future Tech Hub

Website Site Plan

1. Site Name

Name: Bright Future Tech Hub

Reasoning: I chose this name because it directly connects my personal brand with an empowering mission: providing students and aspiring developers in Lagos with accessible, structured pathways into technology careers.

Optional Domain: brightfuturetech.org

2. Site Purpose

Bright Future Tech Hub serves as a community resource platform for early-career developers. The site provides structured learning paths, lists upcoming regional bootcamps, highlights local tech events, and includes an interactive study group signup form to connect peers.

3. Target Audience Scenarios

  • Scenario 1: "I am a complete beginner in web development living in Lagos. Where can I find curated, structured learning roadmaps and local study groups to keep me accountable?"
  • Scenario 2: "How can I register for upcoming tech bootcamps or contact community mentors for project feedback?"

4. Color Schema

This planning document uses the exact color palette defined for the project site to ensure brand consistency:

Primary: Deep Navy Blue #0b3c5d
Secondary: Ocean Blue #1d70b8
Accent: Warm Amber #f39c12
Background: Light Gray #f8f9fa
  • Primary (#0b3c5d): Header background, main headings (H1, H2), and footer background.
  • Secondary (#1d70b8): Secondary headings (H3), buttons, and navigation hover states.
  • Accent (#f39c12): Call-to-action highlights, active links, and border accents.
  • Background (#f8f9fa): Main body background and card containers (#ffffff).

5. Typography

The website uses two primary Google Fonts to ensure readability and modern design hierarchy:

  • Heading Font: Montserrat (Sans-serif, Bold) – Applied to all <h1>, <h2>, and <h3> headings for a clean, strong visual hierarchy.
  • Body Font: Open Sans (Sans-serif, Normal) – Applied to body text, list items, and paragraph content for optimal screen legibility.
